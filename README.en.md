# Awesome shadcn/ui

[![Netlify Status](https://api.netlify.com/api/v1/badges/9ff7ba09-d830-4891-8344-b65fe0ab87e0/deploy-status)](https://app.netlify.com/projects/awesome-shadcn-ui/deploys)

English | [中文](./README.md)

A filterable, searchable directory of UI libraries that publicly support the shadcn CLI or a compatible registry.

**[Browse online →](https://awesome-shadcn-ui.tuntun.site/)**

## Features

- **Multi-facet filtering**: combine delivery type (components / blocks / templates), use case (marketing, dashboard, commerce, content, data display, AI), pricing, source model, and access model
- **Search**: quick lookup by name, description, and tags
- **GitHub metrics**: stars and latest commit snapshots for each library
- **Detail pages**: a dedicated page per library with links to its site, docs, and install instructions
- **Bilingual UI**: toggle between English and Chinese, with light and dark themes

## Inclusion policy

Inclusion is based on each project's own public claim that it supports the shadcn CLI or a compatible registry. The commands and registries are not verified by this project. Pricing, source availability, and access requirements can change, so the official product site remains the source of truth.

The catalog does not accept submissions for new libraries at this time. GitHub Issues are available only for corrections to existing entries.
